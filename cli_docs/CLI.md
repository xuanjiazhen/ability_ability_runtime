# Role
你是一位拥有 15 年经验的首席软件架构师，擅长JS/C/C++语言，有过大量的系统设计和技术选型经验。

# Task
我们需要设计一个 CLI工具管理框架。

# Context
- 背景：
      在当前的架构下，开发一个CLI管理框架。 提供JS 的API给系统应用调用，支持系统应用（类似openClaw，后面称之为AIClaw）调用系统中已有的CLI二进制工具。
	  CLI工具在运行时，运行在独立进程中。
	  CLI工具能够短时和长时运行，AIClaw调用工具，支持传递参数到CLI工具，能够从CLI工具获取结果。 AIClaw能够异步监听CLI工具发送的消息。
	  新增管理服务（SystemAbilityManager）能够管理所有可用的CLI工具列表，提供查询工具列表、注册工具的能力。
	  定义CLI工具的描述文件，描述文件中包含权限列表、工具的输入输出格式。
- 当前技术栈: JS C++
- 约束条件: 
       1. 团队擅长JS C++语言;
	   2. 核心逻辑使用C++编写，对外的JS API只是一层封装;
	   3. JS层的API要易用;
	   4. 目录结构遵循现有架构;
- 核心目标：
         1. AIClaw使用统一的范式调用系统中的CLI工具，不用关心工具的细节;
		 2. AIClaw是一个系统应用，通过JS API调用CLI工具;
		 3. 定义CLI工具的描述文件;
		 4. AIClaw进程能够跟工具进程进行通信;
		 5. 核心模块包括但不限于：CLI管理服务， CLI客户端，对外的JS桥接层，JS API定义、工具的描述文件等。
