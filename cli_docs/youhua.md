欢迎使用 CLI 工具管理框架！本章节帮助你在 15 分钟内创建第一个 CLI 工具。

### 2.1 开发流程概览

步骤1: 创建目录结构      [2分钟]

### 2.2 最小化示例：Hello World 工具

让我们创建一个最简单的 CLI 工具，它只输出 "Hello, World!"。

#### 步骤1: 创建目录结构

```bash
mkdir -p /usr/local/src/cli-tools/hello-world/{src,include,tests}
cd /usr/local/src/cli-tools/hello-world
```

#### 步骤2: 编写工具代码

创建 `src/main.cpp`：
```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

#### 步骤3: 创建描述文件

创建 `/etc/cli/tools/hello-world.json`：
```json
{
  "name": "hello-world",
  "version": "1.0.0",
  "description": "A simple Hello World tool",
  "executable": "/usr/bin/hello-world",
  "input": {
    "type": "object",
    "properties": {}
  },
  "output": {
    "type": "object",
    "properties": {
      "message": {
        "type": "string",
        "description": "Output message"
      }
    }
  },
  "argumentMapping": {
    "type": "flag",
    "templates": {}
  },
  "timeout": 5000,
  "events": ["result"]
}
```

#### 步骤4: 本地测试

```bash
# 编译
g++ -o hello-world src/main.cpp
sudo cp hello-world /usr/bin/

# 直接运行测试
/usr/bin/hello-world
# 输出: Hello, World!

# 验证 JSON 格式
jq . /etc/cli/tools/hello-world.json
```

#### 步骤5: 从应用调用

```typescript
import CLI from '@ohos.cli.manager';

const result = await CLI.CLIManager.execTool('hello-world', {});
console.log(result.data.message);
// 输出: Hello, World!
```

🎉 恭喜！你已经创建了第一个 CLI 工具！

```
